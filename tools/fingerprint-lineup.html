How to record the demo. Open this page with the VPN off and pin a reading. Turn Mullvad VPN on, reload, check your new IP at mullvad.net/check, and pin a second reading. The IP changes; the fingerprint does not. Then open this same page in Mullvad Browser, copy the transfer code from your first browser, import it, and pin a third — that one finally moves.

Everything is computed in your browser and stored only in this browser. Nothing is sent anywhere. The ID is a hash of the signals listed above; it is a stable label for this browser configuration, not a measure of how rare you are. For a population-based estimate of that, use EFF Cover Your Tracks.
